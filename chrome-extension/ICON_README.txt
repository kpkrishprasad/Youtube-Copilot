ICON PLACEHOLDER
================

The extension needs an icon.png file (128x128 pixels).

You can:
1. Create one using any image editor (Photoshop, Figma, Canva, etc.)
2. Download a free icon from https://www.flaticon.com/
3. Use the icon.svg file provided and convert it online at https://cloudconvert.com/svg-to-png

For now, you can use a temporary icon by visiting:
https://placeholder.com/128x128

Or create a simple one with this command (requires ImageMagick):
  convert -size 128x128 xc:purple -pointsize 80 -fill white -gravity center -annotate +0+0 "✨" icon.png

The extension will work without the icon, but Chrome will show a default placeholder.
